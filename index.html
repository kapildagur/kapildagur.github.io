fastapi-tenancy
📦 PyPI
⌥ GitHub ↗ PyPI ↗ Docs

Serving many customers from one FastAPI app means working out which tenant a request belongs to, scoping every query to it, and keeping migrations in step. fastapi-tenancy does that for you. Choose schema per tenant, database per tenant, row-level security or a mix; it stays fully async and runs on PostgreSQL, MySQL, SQLite and SQL Server. It lives under @fastapi-extensions, an organisation I started for well-tested FastAPI add-ons.

🌐
fastapi-locale
⌥ GitHub ↗ PyPI ↗ Docs

An API that speaks one language turns away part of its users. fastapi-locale reads the language a client asks for, from a query parameter, Accept-Language or a cookie, and answers in it: messages, validation errors with the right plural forms, and the Content-Language header. Translations live in standard gettext catalogs, managed by a small command line tool.

FastAPI Pydantic Babel gettext
95% coverage gate in CI Release candidate Author & maintainer
