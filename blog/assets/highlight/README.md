# highlight.js

Syntax highlighting for the blog's code blocks.

- `highlight.min.js`: highlight.js 11.11.1, common-languages build, from
  `@highlightjs/cdn-assets` on npm.
- `dockerfile.min.js`: the Dockerfile language from the same release.
- `init.js`: runs the highlighter on page load.
- `LICENSE`: BSD-3-Clause licence of highlight.js.

The colour theme lives in `../../blog.css` under "Syntax highlighting".
